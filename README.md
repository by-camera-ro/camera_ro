# by camera ro

Minimal photography portfolio for GitHub Pages.

## Structure
- **Architecture** — current photography selection.
- **Portrait** — prepared for future portrait work.

## Visual direction
- Minimal editorial header with categories centered at the top.
- Smaller photographs with generous white space.
- 3 / 4 / 3 editorial rhythm on desktop.
- Two-column rhythm on mobile.
- Images keep their original proportions; no forced card cropping.
- Click a photograph to open the full-screen viewer.

## Image files
The website uses optimized WebP copies. Original photographs are not included.
